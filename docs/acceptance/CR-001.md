## 已知边界行为（非 P0，记入技术债）

1. **bump/sync 后 `check` 会报锁文件不一致**（Cargo.lock 等只读 target）：设计语义为锁文件由工具链重新生成（`cargo build` / `uv sync` / `flutter pub get`），README 已说明。
2. **修改 `tag_prefix` 后旧前缀 tag 不再被识别**，权威源回退 0.0.0；此时若跑 `sync` 且 provider 非只读，会把 0.0.0 写进已有版本文件。建议后续迭代加"无 tag 时拒绝 sync 写入"保护。
