## 需求原文（逐字记录，未脑补）

> 做一个设计，我后面想要添加功能扩展，要能够添加lua插件，来扩展修改项目文件中的版本同步问题。现在只能修改git tag，我希望后面能够直接管理整个项目的版本，比如tauri项目、uv python项目、flutter项目等等。
> 上面是我想要添加功能的设想，你有什么要补充的吗

## 需求理解（经设计讨论收敛，非原文）

- 核心能力扩展：从「只管理 git tag」升级为「管理整个项目的版本同步」
- 支持项目类型：tauri（Cargo.toml + tauri.conf.json）、uv python（pyproject.toml）、flutter（pubspec.yaml）等
- 扩展机制：Lua 插件（provider + hooks，首版范围）
- 已确认设计决策：git tag 为唯一权威源；`--commit` 为 opt-in；Lua 首版支持 provider + hooks
